# Tire Lab v0.8.2 telemetry analysis controls

v0.8.2 fixes the apparent no-op behavior of telemetry analysis. **Import & analyze latest log** now shows progress, opens the Telemetry CSV overlay, preserves a visible success or failure message, and reports the imported sample count. The Validation Workspace also has an explicit **Import & analyze selected CSV** button with a clear no-file error.

The parser, raw telemetry values, tire physics and knowledge data are unchanged.
