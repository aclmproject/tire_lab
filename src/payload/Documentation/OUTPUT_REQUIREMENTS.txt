ACLM TIRE OUTPUT — REQUIRED CONTENT CHECKLIST
=============================================

Each generated compound must contain, at minimum:

TIRE SECTION
- NAME
- SHORT_NAME
- TYPE_HINT
- WIDTH
- RADIUS
- RIM_RADIUS
- RATE
- SIDEWALL_K_MULT
- SIDEWALL_K_MULT_X
- DY_CURVE
- DX_CURVE
- DY0 / DY1
- DX0 / DX1
- WEAR_CURVE
- RELAXATION_LENGTH
- FLEX
- FLEX_GAIN
- CAMBER_GAIN
- DCAMBER_LUT
- DCAMBER_LUT_SMOOTH
- PRESSURE_STATIC
- PRESSURE_IDEAL
- FZ0
- LS_EXPY
- LS_EXPX
- DY_REF
- DX_REF
- FALLOFF_LEVEL
- CX_MULT
- RADIUS_ANGULAR_K
- BRAKE_DX_MOD
- COMBINED_FACTOR

THERMAL SECTION
- SURFACE_TRANSFER
- PATCH_TRANSFER
- CORE_TRANSFER
- INTERNAL_CORE_TRANSFER
- FRICTION_K
- ROLLING_K
- PERFORMANCE_CURVE
- GRAIN / BLISTER parameters
- COOL_FACTOR
- SURFACE_ROLLING_K

EXTERNAL FILES
- front wear LUT
- rear wear LUT
- compound temperature/performance LUT
- front camber LUT
- rear camber LUT

WET / INTERMEDIATE WHEN APPLICABLE
- TYPE_HINT appropriate to treaded/rain tire
- TREAD_DEPTH
- TREAD_COVER

GLOBAL
- [HEADER] VERSION=10
- [COMPOUND_DEFAULT]
- [VIRTUALKM] USE_LOAD=1
- [EXPLOSION]
- [_EXTENSION]
- [ADDITIONAL1]

A generated pack should not be used if the validator reports FAIL.
