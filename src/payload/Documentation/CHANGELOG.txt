2026-08-24 - v0.4.1
- Fixed the LC2 pressure-generation regression exposed by the first Le Mans test.
- Imported PRESSURE_STATIC values are now reference-only. They are shown in the import table/report but are not copied into generated compounds.
- Added automatic generated-cold-pressure solver based on absolute pressure / ideal-gas temperature relation.
- Default cold-pressure reference temperature is 26 C, matching the LC2 test condition that reproduced 24 psi -> 30.47 psi at 76 C and 27 psi -> 36.6 psi at ~95 C.
- Each compound is solved against the center of its actual generated PERFORMANCE_CURVE peak window.
- Soft / Medium / Hard / Intermediate / Wet therefore receive different cold pressures when their target thermal windows differ.
- Added explicit Auto-solve generated cold pressures control; users can disable it for manual pressure calibration.
- Added Cold-pressure reference temp input for different validation conditions.
- Pressure validator now predicts hot pressure at the compound thermal target instead of using a crude cold/hot psi-gap rule.
- Historical PDF report and manifest now distinguish imported AC pressure references from newly generated cold pressures.
- The existing AC PRESSURE_IDEAL remains an import clue but is labeled as a reference rather than primary historical evidence.
- PWA cache bumped so installed Tire Lab users receive the pressure solver.

2026-08-24 - v0.4.0
- Restored the historical tire accuracy/evidence PDF report as a mandatory part of every tire-pack export.
- PDF filename follows the car name: ACLM_<Car>_Historical_Tire_Accuracy_Report.pdf.
- Report includes identity/year/class/supplier provenance, construction, tire geometry, RATE, FZ0, pressure targets, compound menu, wear status, terminal-failure settings, AC implementation status, sources, limitations and next validation items.
- Added an evidence-confidence score and explicit verdict. The score is labeled as evidence confidence, not a probability that proprietary coefficients are exact.
- Direct AC-package data, researched context and Tire Lab reconstruction are explicitly separated in the report.
- Historical source pages selected by the in-app research system are embedded in the PDF source section.
- Report honestly flags unresolved class/supplier context and provisional wear data instead of presenting them as proven historical facts.
- ZIP exporter is now binary-safe so PDFs are packaged alongside INI/LUT/TXT files.
- Generated-file list allows the bundled PDF to be downloaded separately.
- Validator now blocks export if the historical PDF is missing or does not have a valid PDF signature.
- PDF engine is bundled locally and requires no internet connection or third-party PDF library at export time.
