2026-08-24 - v0.4.1

- Imported PRESSURE_STATIC values are now reference-only. They are shown in the import table/report but are not copied into generated compounds.
- Added automatic generated-cold-pressure solver based on absolute pressure / ideal-gas temperature relation.
- Default cold-pressure reference temperature is 26 C, matching the LC2 test condition that reproduced 24 psi -> 30.47 psi at 76 C and 27 psi -> 36.6 psi at ~95 C.
- Each compound is solved against the center of its actual generated PERFORMANCE_CURVE peak window.

- Added explicit Auto-solve generated cold pressures control; users can disable it for manual pressure calibration.
- Added Cold-pressure reference temp input for different validation conditions.
- Pressure validator now predicts hot pressure at the compound thermal target instead of using a crude cold/hot psi-gap rule.
- Historical PDF report and manifest now distinguish imported AC pressure references from newly generated cold pressures.
- The existing AC PRESSURE_IDEAL remains an import clue but is labeled as a reference rather than primary historical evidence.
- PWA cache bumped so installed Tire Lab users receive the pressure solver.
